Deep learning pour la classification d'images satellites

Au-delà des méthodes classiques de machine learning (SVM, K-NN) utilisées dans mes projets, j'explore les réseaux de neurones convolutifs pour la cartographie de l'occupation du sol — avec un objectif de comparaison rigoureuse plutôt que de substitution.

Approche

Pourquoi le deep learning, et pourquoi comparer

Mes projets d'occupation du sol (Massili, Tiogo) reposent sur des classificateurs classiques — SVM et K-NN — entraînés sur un nombre limité de régions d'intérêt. Ces méthodes sont robustes et interprétables, mais restent sensibles à la confusion spectrale entre classes proches (ex. bâti traditionnel / sol nu, savane arborée / savane arbustive).

L'objectif du volet deep learning n'est pas de remplacer ces méthodes mais de les mettre à l'épreuve : entraîner un modèle par transfert d'apprentissage, l'adapter aux mêmes zones d'étude et au même jeu de validation, puis comparer objectivement précision globale et indice Kappa entre les deux approches.

Étape 1 — Modèle de base

CNN entraîné sur EuroSAT

Un réseau de neurones convolutif a été entraîné sur EuroSAT, jeu de données de référence pour la classification de scènes Sentinel-2 (10 classes d'occupation du sol, 27 000 images). Ce modèle sert de point de départ pour le transfert d'apprentissage vers mes propres zones d'étude.

01

Jeu de données

EuroSAT — imagerie Sentinel-2, 10 classes d'occupation du sol, découpage entraînement/validation/test.

02

Architecture

Réseau de neurones convolutif (CNN) implémenté sous PyTorch.

03

Résultat

94,8 % de précision sur le jeu de test — base validée pour l'étape de transfert vers les données de terrain.

Étape 2 — En développement

Transfert vers U-Net, 8 canaux

L'étape suivante consiste à adapter ce modèle de base vers une architecture U-Net, capable de segmentation sémantique pixel par pixel plutôt que de classification de scène entière — indispensable pour produire une carte d'occupation du sol comparable aux classifications SVM et K-NN existantes.

Le modèle sera réentraîné sur 8 canaux (bandes Sentinel-2 B2, B3, B4, B8, B11 + indices NDVI, NDWI, BSI), puis évalué sur les mêmes points de validation indépendants que la classification K-NN du projet Tiogo — pour une comparaison directe, chiffrée en précision globale et indice Kappa.
